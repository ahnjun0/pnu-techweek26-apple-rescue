# Phase 5 — 걸어다니는 사람 다루기

대회 과제에서 제일 까다로운 부분이다. 사람은 움직이고, 로봇보다 빠르고,
Webots 의 `Pedestrian` 은 physics 가 없는 **운동학 물체**라 로봇을 무한한 힘으로 민다.

## 겪은 실패들

| 증상 | 원인 | 고친 방법 |
|---|---|---|
| 로봇이 아레나 밖 **58만 km** 로 날아감 | 보행자가 한 스텝에 로봇을 깊이 관통 → 솔버 폭발 | `basicTimeStep` 32 → **16** |
| 오도메트리 **116 m** 오차 | 위와 같음 | 위와 같음 |
| APPROACH 가 900초 동안 안 끝남 | 탈출 중에는 `_goal_age` 가 안 늘어 시간 초과가 영영 안 걸림 | **시계는 탈출 중에도 돈다** |
| RETURN 이 300초 동안 얼어붙음 | 경로를 못 찾으면 "다시 시도" 만 반복 | 직선을 긋고 DWA 에 맡기는 폴백 + 전체 시간 초과 |
| 아레나 밖 `(-3.8, 3.0)` 에 목표물 등록 | 오도메트리가 틀어진 채 탐지 | 지도 밖 위치는 버린다 |
| 보행자 통로 위에 **가짜 목표물 2개** | 멀리 있는 목표물을 보는데 그 방향 앞으로 사람이 지나가 LiDAR 가 짧은 거리를 줌 | **각폭·거리 일관성 검사** |
| 목표물 인정 기준을 가짜가 통과 | 기준이 3회인데 가짜가 딱 3회 | **8회** 로 (진짜는 32~488회) |
| 밀리는 동안 못 빠져나옴 | 탈출 속도 0.075 m/s < 사람 0.4 m/s | 탈출은 **전속력** |

## 각폭·거리 일관성 검사

반지름 r 인 물체를 거리 d 에서 보면 화면상 각폭은 대략 `2·atan(r/d)` 다.
카메라가 본 각폭과 LiDAR 가 준 거리가 이 관계에서 크게 벗어나면,
**방위각과 거리가 서로 다른 물체를 가리키고 있다는 뜻**이다.

```
3 m 짜리 목표물의 각폭 3.8°  vs  1 m 거리에서 기대되는 11.4°
→ 앞뒤가 안 맞는다 → 버린다
```

이것 하나로 보행자가 만들던 가짜 목표물이 사라졌다.

## 측정으로 정한 행동

가짜 보행자 월드(`tests/fake_world.crowded_world`)에서 **4개 위상**으로 재서 정했다.
보행자는 LiDAR 에 잡히고 로봇을 민다 — 실제 위험을 모델해야 판단이 맞는다.

| 설정 | 완주 | 시간 | 목표 | 접촉 | 판정 |
|---|---|---|---|---|---|
| 다가오면 멈춰 기다리기 **끔** | 4/4 | 288 s | 3.0/3 | 318 | |
| 다가오면 멈춰 기다리기 **켬** | 4/4 | **269 s** | 3.0/3 | **213** | ✅ 켠다 |
| 사람 지나간 자리 경로 회피 **끔** | 4/4 | **311 s** | 3.0/3 | **366** | ✅ 끈다 |
| 사람 지나간 자리 경로 회피 **켬** | 4/4 | 326 s | 3.0/3 | 412 | |

사람은 계속 움직이므로 "지나갔던 자리" 를 피해 봐야 지금 사람이 있는 곳과는
다르고, 경로만 길어진다. 반대로 "지금 다가오는 것" 앞에서 잠깐 서는 것은 효과가 있다.

## ⚠️ 측정이 거짓말을 한 적이 있다

처음엔 **"기다리기는 나쁘다"** 는 반대 결론이 나왔다 (접촉 5544 vs 6958).

원인은 가짜 월드였다. 벽에 박힌 로봇의 **이동을 전부 막아** 놔서, 한 번 끼면
탈출 동작이 아무리 옳아도 영영 못 나왔다. 그 상태로 잰 숫자는
"탈출도 기다림도 소용없다" 고 말했다.

실제 물리에서는 눌린 로봇도 후진해서 빠져나올 수 있다. 그렇게 고치자
같은 실험에서 결론이 **뒤집혔다**.

> **가짜 월드가 실제 실패 방식을 모델하지 못하면, 측정은 확신을 가지고 틀린 답을 준다.**

## 남은 한계

`practice.wbt` 에서 목표물 1번(−2.2, 1.8)으로 가는 길은 보행자 통로(y=0.8)를
**왼쪽 벽 근처에서 가로지른다.** 거기서 짧은 접촉이 한 번 남는다.
로봇이 통로를 건너는 동안 사람이 오면 피할 공간이 좁기 때문이다.

대회장에서도 같은 상황이 생길 수 있다. 완화 방법:
- `SAFETY_YIELD_DISTANCE` 를 키워 더 일찍 기다린다 (탐색은 느려진다)
- 목표물이 벽에 가까우면 접근 방향을 벽 반대쪽에서 잡는다 (미구현)
